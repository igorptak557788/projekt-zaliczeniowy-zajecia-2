# Opis projektu

Projekt dotyczy aplikacji wspomagającej planowanie nauki. Rozwiązuje problem braku
struktury i przeciążenia informacjami podczas studiów.

Odbiorcami aplikacji są osoby w wieku **18–25 lat**, które chcą lepiej organizować
zadania oraz czas nauki.

## Zakres funkcjonalny

W aplikacji przewidziano następujące funkcje:
- lista zadań
- tygodniowy kalendarz do planowania sesji nauki
- proste statystyki postępów
- przypomnienia o zaplanowanych zadaniach
- grupowanie zadań według przedmiotów
